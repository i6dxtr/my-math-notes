> [!definition]
> Let $f:E\rightarrow \mathbb{R}$ be a function. $\lim_{x \to p}f( x )=L$ *if and only if* for any sequence $( x_{n} )$ in $E$ with $x_{n}\longrightarrow p$, $\lim_{n \to \infty}f( x_{n} )=L.$ $$\lim_{x \to p}f( x )=L\ \Longleftrightarrow\ \lim_{n \to \infty}f( x_{n} )=L. $$
> [!theorem]
> Suppose $E\subseteq \mathbb{R}$ where $f, g:E\rightarrow \mathbb{R}$ and $p$ is a [[limit point]] of $E$. If: $$\begin{gathered} \lim_{x \to p}f( x )=A&\text{and}&\lim_{x \to p}g( x )=B \end{gathered}$$... then the following hold: $$\begin{align} &1.)\lim_{x \to p}\left[ f( x )+g( x ) \right]=A+B \\ &2.) \lim_{x \to p}( f( x )g( x ) )=AB \\ &3.) \lim_{x \to p}\frac{f( x )}{g( x )} =\frac{A}{B}\text{ where }B\ne 0.\end{align}$$
> [!proof]
> ##### of 1.) using sequences:
> - Let $( P_{n} )$ be a sequence in $E$ satisfying:
> 	- $P_{n}\rightarrow p \Longrightarrow \lim_{n \to \infty}f( P_{n} )=A$
> 	- $\lim_{n \to \infty}g( P_{n} )=B$
> - Apply the result for sequences: $$\begin{align} &\lim_{n \to \infty}f( P_{n} )+ g( P_{n} )&=A+B \\ \Longrightarrow & \lim_{x \to p}f( x )+g( x )&= A+B. \end{align}$$
> ##### of 1.) using a direct proof
> - We know $\lim_{x \to p}f( x )=A$ *if and only if:*
> 	- $\forall\varepsilon>0,$ if $0<\lvert x-p \rvert<\delta$ then $\lvert f( x )0A \rvert<\varepsilon.$
> - Moreover, $\lim_{x \to p}g( x )=A$ *if and only if:*
> 	- $\forall\varepsilon>0, \exists\delta_{2}>0$ such that if $0<\lvert x-p \rvert<\delta_{2}$ then $\lvert g( x )-B \rvert<\frac{\varepsilon}{2}.$
> - Let $\delta=\text{min}\left\{ \delta_{1}, \delta_{2} \right\}$
> - If $0<\lvert x-p \rvert<\delta,$ then the following are true:
> 	- $\lvert f( x )-A \rvert<\frac{\varepsilon}{2}$
> 	- $\lvert g( x )-B \rvert<\frac{\varepsilon}{2}.$
> - Furthermore, $$\begin{align} \lvert f( x )+g( x )-( A+B ) \rvert &=\lvert ( f( x )-A )+( g( x )-B ) \rvert \\ &\leq \lvert f( x )-A \rvert +\lvert g( x )-B \rvert \\ &< \frac{2\varepsilon}{2} \\ &=\varepsilon. \end{align}$$
> - Therefore, $\lvert f( x )+g( x )-( A+B ) \rvert<\varepsilon.$
> - Thus, $\lim_{x \to p}( f( x )+g( x ) )=A+B.$ **qed**
> [!corollary]
> Let $f:E\rightarrow\mathbb{R}.$ We can say $f$ is bounded if $\exists M\in \mathbb{R}$ such that $\lvert f( x ) \rvert\le M$ for all $x\in E.$
> [!theorem]
> Let $E\subseteq \mathbb{R}$ and let $p$ be a limit point of $E$. Suppose $f,g,h$ are functions defined on $E$ satisfying the equality: $$f( x )\le h( x )\le g( x )$$... where $$\lim_{x \to p}f( x )=\lim_{x \to p}g( x )=L.$$... then, the following is true: $$\lim_{x \to p}h( x )=L.$$
> [!corollary]
> Let $f:E\rightarrow \mathbb{R}$ such that $E\cap( a, \infty )\ne \emptyset$ for all $a\in \mathbb{R}$. We can say $\lim_{x \to \infty}f( x )=L$ *if and only if* $\forall\varepsilon>0, \exists M>0$ such that if $x\in E\cap ( M, \infty ),$ then $\lvert f( x )-L \rvert<\varepsilon.$
> $$\begin{gathered} \lim_{x \to \infty}f( x )=L \\ \Longleftrightarrow \\ \forall \varepsilon>0, \exists M>0 \\st. \\ x\in E\cap( M, \infty )\longrightarrow \lvert f( x )-L \rvert <\varepsilon. \end{gathered}$$

> [!remark]
> Suppose $\lim_{x \to p}f( x )=\infty.$ Then $\forall k>0, \exists \delta>0$ such that if $0<\lvert x-p \rvert<\delta$ and $x\in E$, then $f( x )\ge k.$ In short, $x\in E\cap ( N_{\delta}( p )-\left\{ p \right\} ).$ $$\begin{gathered} \lim_{x \to \infty}f( x )=\infty \\ \Longleftrightarrow \\ \forall  k>0, \exists \delta>0 \\ st. \\ 0<\lvert x-p \rvert <\delta \text{ and } x\in  E \\ \text{implies} \\ f( x )\ge k. \end{gathered}$$

Note that $x>M$ and $x\in E$. $$\begin{gathered} \lim_{x \to \infty}f( x )=-\infty \\ \Longleftrightarrow \\ \forall  k<0, \exists M>0 \\ st. \\ x\in  E\cap( M, \infty ) \longrightarrow f( x )<k. \end{gathered}$$
#### Continuous Functions
> [!definition]
> Let $f:E\rightarrow \mathbb{R}$ and $a\in E$. We say $f$ is **continuous** at $a$ if $\forall \varepsilon>0, \exists \delta>0$ such that if $\lvert x-a \rvert<\delta$ and $x\in E$, then $\lvert f( x )-f( a ) \rvert<\varepsilon.$ In other words, $\forall\varepsilon>0, \exists \delta>0$ such that if $x\in N_{\delta}( a )\cap E$, then $f( x )\in N_{\varepsilon}( f( a ) ).$ $$\begin{gathered} f\text{ continuous at }a \\ \Longleftrightarrow \\ \forall \varepsilon>0\ \exists \delta>0 \\st. \\ \lvert x-a \rvert <\delta \text{ and } x\in E \longrightarrow \lvert f( x )-f( a ) \rvert <\varepsilon \\ ie. \\ f( x )\in  N_{\varepsilon}( f( a ) ). \end{gathered}$$
> [!remark]
> 1. If $a$ is a [[limit point]] of $E$, then: $$\lim_{x \to a}f( x )=f( a ).$$
> 2. If $a$ is an *isolated point* of $E$, then $f$ is continuous at $a$.
