#### Uniform convergence & differentiation
> [!theorem]
> Suppose $( f_{n} )$ is a sequence of functions on $\left[ a,b \right]$ satisfying the following:
> 1. $( f_{n}' )$ converges uniformly on $\left[ a,b \right]$
> 2. $f_{n}( x_{0} )$ converges for $x_{0}\in \left[ a,b \right]$
> ... then, $( f_{n} )$ converges uniformly to some function $f$ on $\left[ a,b \right].$ Moreover, $$f'( x )=\lim_{n \to \infty}f_{n}'( x ).$$

> [!remark]
> Let: $$g_{n}( x )=\frac{x^{n}}{n}+( -1 )^{n}, \ \ x\in \left[ 0, \frac{1}{2} \right].$$
> - take $g_{n}'( x )=x^{n-1}$
> - suppose $g'( x )$ converges to $0$ uniformly
> - *but*, $g_{n}( x )$ is *divergent* for any $x\in \left[ 0, \frac{1}{2} \right].$
> ---
> Let: $$h_{n}( x )=\frac{x^{n}}{n},\ \ x\in  \left[ 0,1 \right].$$
> - $h_{n}$ converges to $0$ uniformly
> - take $h'_{n}=x^{n-1}$
> - then $h_{n}'( 1 )$ converges to $1$
> - *but,* $1$ doesn't equal the derivative of the limit of $( h_{n} ).$

> [!proof]
> Suppose: $$( f_{n}( x_{0} ) )_{n\ge 1}\text{ is Cauchy.}$$
> - Then, for $\varepsilon>0$ there exists $n_{0}$ such that if $n,m\ge n_{0}$ then $\lvert f_{n}( x_{0} )-f_{n}( x_{0} ) \rvert\le \varepsilon$
> - We'll show that $( f_{n}' )$ satisfies the Cauchy Criterion: $\varepsilon>0$ $\exists n_{0}$ st. if $n,m\ge n_{0}$ then $\lvert f_{n}( x )-f_{m}( x ) \rvert<\varepsilon$ for all $x\in \left[ a,b \right].$
> - Appy Mean Value Theorem: $\lvert ( f_{n}( x )-f_{m}( x ) )-f( f_{n}( y )-f_{m}( y ) ) \rvert$ $= \lvert f_{n}'( t )-f_{m}'( t ) \rvert\ \lvert x-y \rvert \ \text{for some }t\in \left[ x,y \right]$
> - If $n,m\ge \text{max}\left\{ n_{0}, m_{0} \right\}$ where $y=x_{0}$
> 	- then $\lvert ( f_{n}( x )-f_{m}( x ) )-( f_{n}( x_{0} )-f_{m}( x_{0} ) ) \rvert<\varepsilon\lvert x-x_{0} \rvert$ for all $x\in \left[ a,b \right]$
> 	- further,
> 		$$
> 		\begin{align} \lvert f_{n}( x )-f_{m}( x ) \rvert &\le \varepsilon \lvert x-x_{0} \rvert+\lvert f_{n}( x_{0} )-f_{m}( x_{0} ) \rvert \\ &<\varepsilon\lvert x-x_{0} \rvert+\frac{\varepsilon}{2} \\ &<\frac{\varepsilon\lvert x-x_{0} \rvert}{2\lvert a-b \rvert} \\ &<\varepsilon \end{align}
> 		$$
> 		... for all $x\in \left[ a,b \right].$
> ---
##### Verifying that $f'( x )=\lim_{n \to \infty}f'_{n}( x )$
- Fix $p\in \left[ a,b \right]$
- Then see $f'( p )=\lim_{t \to p}\frac{f( t )-f( p )}{t-p}$
- *Recall: If $g_{n}\rightarrow g$ uniformly, then $\lim_{n \to p}\lim_{x \to p}g_{n}( x )$ $=\lim_{x \to p}\lim_{m \to \rightarrow}g_{n}( x ).$*
- So:
	$$
	\begin{align} f'( p )&=\lim_{t \to p}\lim_{n \to \infty}\frac{f_{n}( t )-f_{n}( t )}{t-p} &= g_{n}( t ) \\ &=\lim_{n \to \infty}\left(  \lim_{t \to p} \frac{f_{n}( t )-f_{n}( p )}{t-p} \right) \\ &= \lim_{n \to \infty} f_{n}'( p ). \end{align}
	$$
