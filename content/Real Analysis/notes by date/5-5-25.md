### Continuity vs Uniform Continuity
- Suppose $f:E\rightarrow \mathbb{R}$ is a continuous function. If $( x_{n} )$ is a *convergent sequence* in $E,$ (where $x_{n}\rightarrow x$ in $E$) then $f( x_{n} )\rightarrow f( x )$
- Suppose $f:E\rightarrow \mathbb{R}$ is a uniformly continuous function. If $( x_{n} )$ is a Cauchy sequence, then $( f( x_{n} ) )_{n\ge 1}$ is a Cauchy sequence.
- We can say $f$ is uniformly continuous *if and only if* $\forall \varepsilon>0,$ $\exists \delta>0$ such that if $\lvert x,y \rvert<\delta$ where $x,y\in E$ then $\lvert f( x )-f( y ) \rvert<\varepsilon.$
- For $\delta>0,$ $\exists n_{0}$ such that if $n,m\ge n_{0}$ and $\lvert x_{n}-x_{m} \rvert<\delta$ for $x_{n}, x_{m}\in E$ then $\lvert f( x_{n} )-f( x_{m} ) \rvert<\varepsilon.$

ad-example
$$\begin{gathered} f:( 0,1 )\rightarrow\mathbb{R} \\ f( x )=\frac{1}{x} \\ \underline{f \text{ is continuous.}}  \end{gathered}$$
- $x_{n}=\frac{1}{n}$
- $( x_{n} )$ is Cauchy in $( 0,1 )$
- $f( x_{n} )=f\left(  \frac{1}{n}  \right)=m$
- $( f_{n}( x ) )_{n\ge1}$ is *not* bounded


### Non-uniformly continuous functions
ad-example
$f( x )=x^{2}$ is not uniformly continuous
1. $f:\mathbb{R}\rightarrow \mathbb{R}$
2. If it's uniformly continuous, then $\exists \varepsilon_{0}$ such that $\forall\delta>0,$ $\exists x,y$ such that $\lvert x-y \rvert<\delta$ but $\lvert f( x )-f( y ) \rvert\ge \varepsilon_{0}.$ 
3. Let $x=n$ and $y=n+\frac{1}{n}$
4. Then $\lvert x-y \rvert=\frac{1}{n},$ a small number
5. So $$\begin{align} \lvert f( x )-f( y ) \rvert&=\left\lvert  n^{2}-\left(  n+\frac{1}{n}  \right)^{2}  \right\rvert\\ &=\left\lvert  n^{2}-\left(  n^{2}+2+\frac{1}{n^{2}}  \right)  \right\rvert \\ &=2+\frac{1}{n^{2}}\end{align}$$
6. Let $\varepsilon_{0}=1$ and for $\delta>0$ choose $n_{0}$ such that for all $n\ge n_{0}, \frac{1}{n}<\delta$ 
7. We know $x=n$ and $y=n+\frac{1}{n}$, so $\lvert x-y \rvert=\frac{1}{n}<\delta,$ but $\lvert f( x )-f( y ) \rvert=2+\frac{1}{n^{2}}>1.$

$$\begin{gathered} f( x )=x \sin\left(  \frac{1}{x}  \right),\ \  x\in (0,1] \\ \underline{f\text{ is uniformly continuous.}} \end{gathered}$$
- Take $\lim_{x \to \infty}x\sin \left(  \frac{1}{x}  \right)=0$, so $0<\left\lvert  x\sin\left(  \frac{1}{x}  \right)\  \right\rvert \le \lvert x \rvert$
- Observe: $\varepsilon>0$ $\exists \delta>0$ such that if $\lvert x \rvert<\delta$ then $\lvert f( x ) \rvert<\varepsilon.$
- $\left[ \delta, 1 \right]$ is compact: $f$ is uniformly continuous on $\left[ \delta, 1 \right]$
- So $\varepsilon>0$ $\exists \delta_{1}$ such that if $x,y\in \left[ \delta, 1 \right]$ and $\lvert x-y \rvert<\delta_{1}$ then $\lvert f( x )-f( y ) \rvert.$
- Take $\delta'=\text{min}( \delta, \delta_{1} )$
- Then for $x,y\in (0, 1],$ $\lvert x-y \rvert<\delta'.$
- *Case 1:* $x,y\in ( 0, \delta ).$ Then $\lvert f( x )-f( y ) \rvert<2\varepsilon$
- *Case 2:* $x,y\in [\delta, 1).$ Then $\lvert f( x )-f( y ) \rvert<\varepsilon$
- *Case 3:* $x\in ( 0, \delta ).$ Then $x\in ( 0, \delta )$ and $y\in [\delta, 1).$
- Thus, $$\begin{align} \lvert f( x )-f( y ) \rvert &\le \lvert f( x )-f( \delta ) \rvert + \lvert f( \delta )-f( y ) \rvert \\ &\le 3\varepsilon. \end{align}$$
