*recall uniform convergence*
> [!remark]
> If $f_{n}\rightarrow f$ is uniformly convergent, then $f_{n}\rightarrow f$ is pointwise convergent
> [!example]
> $$f_{n}:\left[ 0,1 \right]\rightarrow \mathbb{R},\ \ f_{n}( x )=x^{n}$$
> - $f_{n}\rightarrow f$ pointwise where $f( x )=\begin{cases} 0&\text{if }0\le x<1 \\ 1&\text{if }x=1. \end{cases}$
> - $( f_{n} )$ does *not* converge uniformly to $f$
> 	- Suppose for sake of contradiction that $f_{n}\rightarrow f$ converges uniformly. Then for $\varepsilon>0,$ $\exists n_{0}$ such that if $n\ge n_{0},$ $x^{n}<\varepsilon$ for $0\le x<1.$ Note: $1^{n}-1=0<\varepsilon.$ Take $0<\varepsilon<1.$ Let $y\in \mathbb{R}$ where $\varepsilon<y<1.$ Fix $n_{0}$ and take $x=y^{1 / n_{0}}.$ Then $f_{n_{0}}( x )=y>\varepsilon,$ a contradiction.
> ---
> $$\begin{gathered} g_{n}:\left[ 0, \frac{1}{2} \right]\rightarrow \mathbb{R}\ \ g_{n}( x )=x^{n} \\ g_{n}\rightarrow 0\text{ uniformly.} \end{gathered}$$
> - Applying definition of convergence: $\lvert g_{n}( x )-0 \rvert=x^{n}$ where $0\le x\le \frac{1}{2}$
> - Then $\lvert g_{n}( x )-0 \rvert\le \left(  \frac{1}{2}  \right)^{n}$
> - Applying definition of limit, $\forall\varepsilon>0$ $\exists n_{0}$ such that if $n\ge n_{0},$ $\left(  \frac{1}{2}  \right)^{n}<\varepsilon.$
> - This implies $\lvert g_{n}( x ) \rvert<\varepsilon,$ $\forall x\in \left[ 0, \frac{1}{2} \right].$
> 
> ---
> [!theorem]
> Recall the definition of uniform continuity. Let $A_{n}=\left\{ \lvert f_{n}( x )-f( x ) \rvert:x\in E \right\}$ where $n\ge n_{0}.$ Then consider $\varepsilon$ as an upper bound of $A_{n}.$ So for $\varepsilon>0,$ $\exists n_{0}$ such that $\forall n\ge n_{0},$ $\text{sup}_{x\in E}\lvert f_{n}( x )-f( x ) \rvert<\varepsilon$ is a *sequence of real numbers.*
> From this, we derive the fact: $$\lim_{n \to \infty}\text{sup}_{x\in  E}\lvert f_{n}( x )-f( x ) \rvert =0.$$
> [!example]
> $$s_{n}( x )=nxe^{-nx^{2}},\ \ x\in  \left[ 0,1 \right]$$
> - *Claim:* $s_{n}\rightarrow 0$ pointwise.
> 	- If $x=0,$ then $s_{n}( 0 )=0$
> 	- If $x\ne 0,$ then $nx\rightarrow \infty$ and $e^{-nx^{2}}\rightarrow0$
> 	- Applying L'hopital: $nxe^{-nx^{2}}=\frac{nx}{e^{nx^{2}}}$
> 	- So $\lim_{n \to \infty}\frac{nx}{e^{nx^{2}}}=\lim_{n \to \infty}\frac{x}{x^{2}e^{nx^{2}}}=0.$
> - *Claim:* $\text{sup}_{x\in \left[ 0,1 \right]}\lvert s_{n}( x ) \rvert=\text{max}_{x\in \left[ 0,1 \right]}s_{n}( x )$
> 	- Observe: $$\begin{align} s_{n}'( x )&=ne^{-nx^{2}}+nx( -2nx )e^{-nx^{2}} \\ &=0 \\ &\Longleftrightarrow n-2n^{2}x^{2}  = 0 \\ x&=\sqrt{\frac{1}{2n}}\end{align}$$... so: 
> 		- $s_{n}( 0 )=0$
> 		- $s_{n}( 1 )=ne^{-n}$
> 		- $s_{n}\left(  \sqrt{\frac{1}{2n}}  \right)=n\left(  \sqrt{\frac{1}{2n}}  \right)e^{-n\left(  \frac{1}{2n}  \right)}=\sqrt{\frac{n}{2}}\cdot e^{-\frac{1}{n}}$
> - Moreover, 
> 	- $M_{n}=\text{sup}_{x\in \left[ 0,1 \right]}\lvert s_{n}( x ) \rvert=\sqrt{\frac{n}{2}}e^{-\frac{1}{2}}$
> 	- See that $M_{n}\rightarrow \infty,$ in particular, $M_{n}\not\rightarrow0,$ so $s_{n}$ does not converge uniformly at $0.$
> ---
> ##### Alternate proof (estimating $\text{sup}_{x\in \left[ 0,1 \right]}\lvert s_{n}( x ) \rvert.$)
>    Take $s_{n}( x )=nxe^{-nx^{2}},$ and let $x=\frac{1}{n}.$ Then: $$\begin{align} s_{n}\left(  \frac{1}{n}  \right)&=n\left(  \frac{1}{n}  \right)e^{-n\frac{1}{n^{2}}} \\ &=e^{-\frac{1}{n}} \\ &\rightarrow 1. \end{align}$$... however, $\text{sup}_{x\in \left[ 0,1 \right]}\lvert s_{n}( x ) \rvert\ge s_{n}\left(  \frac{1}{n}  \right),$ so $s_{n}( x )$ necessarily does not uniformly converge to $0.$
#### Cauchy criterion
> [!definition]
> Let $f_{n}:E\rightarrow\mathbb{R}$ for some $n\ge 1.$ We say $( f_{n} )$ converges uniformly *if and only if* $all\varepsilon>0, \exists n_{0}$ such that if $n,m\ge n_{0},$ then $\lvert f_{n}( x )-f_{m}( x ) \rvert<\varepsilon$ for all $x\in E.$
> [!corollary]
> The series $\sum_{n=0}^{\infty}f_{n}( x )$ converges uniformly *if and only if* $\forall\varepsilon>0,$ $\exists n_{0}$ such that if $n,m\ge n_{0}$ then $$\left\lvert  \sum_{k=n+1}^{m}f_{k}( x )  \right\rvert <\varepsilon,\ \ \forall  x\in  E.$$
