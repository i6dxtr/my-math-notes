#### Dini's theorem
ad-theorem
Let $K$ be a compact subset of $\mathbb{R}.$ Suppose $( f_{n} )$ is a sequence of continuous functions defined on $K$ satisfying the following:
1. $f_{n}$ converges pointwise on $K$ to a continuous function $f.$
2. $f_{n}( x )\ge f_{n+1}( x )$ for all $x\in K$
Then $( f_{n} )$ converges uniformly to $f$ on $K.$

ad-remark
Take the series of functions of the form $f_{n}( x )=x^{n}\text{ on }( 0,1 ).$
- All $f_{n}$ are continuous
- $f_{n}( x )\rightarrow 0$ for all $x\in ( 0,1 )$
- $f_{n}( x )=x^{n}\ge x^{n+1}=f_{n+1}( x ).$ (decreasing)
- $f_{n}$ *does not converge to $0$ uniformly.*
	- $( 0,1 )$ is *not* compact.

---

Take $g_{n}( x )=nxe^{-nx^{2}}$ on $x\in \left[ 0,1 \right].$
- All $g_{n}$ are continuous
- $g_{n}( x )$ converges to $0$ for all $x\in \left[ 0,1 \right]$
- $g_{n}$ *does not converge to $0$ uniformly.* 
	- $g_{n}( x )\ge g_{n+1}( x )$ $\forall x\in \left[ 0,1 \right],$ $\forall n\ge 1.$

ad-proof
We want to prove for $\varepsilon>0$ $\exists n_{0}$ such that for $n\ge n_{0},$ $\lvert f_{n}( x )-f( x ) \rvert<\varepsilon$ for all $x\in K.$
Let $g_{n}( x )=f_{n}( x )-f( x ).$
We know all $g_{n}$ are continuous.
We have shown that $g_{n}( x )\ge g_{n+1}\ge 0.$
Set $K_{n}=\left\{ x\in K: g_{n}( x )\ge \varepsilon \right\}.$
We'll show $K_{n}$ is closed:
Take $K_{n}=g_{n}^{-1}( \left[ \varepsilon, \infty \right] ),$ which is closed, with the inner term also being closed
This implies $K_{n}$ is compact. Moreover, $K_{n+1}\subseteq K_{n}$ for all $n\ge 1$
If $x\in K_{n+1},$ $g_{n+1}( x )\ge \varepsilon,$ btu $g_{n}( x )\ge g_{n+1}( x )$ implies $g_{n}( x )\ge \varepsilon$ implies $x\in K_{n}$
Therefore, $\bigcap_{n=1}^{\infty}K_{n}= \emptyset,$ since if $x\in K,$ $\lim_{n \to \infty}g_{n}( x )=0,$ $\exists N$ such that if $n\ge N,$ $g_{n}( x )<\varepsilon.$ This implies $x\notin K_{n}$
Conclusion: $\exists n_{0}$ such that $K_{n_{0}}=\emptyset$ 
For all $x\in K,$ $x\notin K_{n_{0}},$ implying $g_{n_{0}}<\varepsilon$
Which implies $\forall n\ge n_{0},$ $g_{n}( x )<\varepsilon$ for all $x\in K.$

#### Uniform convergence and integration
*Recall:* $f_{n}=nx( 1-x^{2} )^{n}$
- $f_{n}\in R\left[ 0,1 \right]$
- Observe the pointwise limit:
	- $f_{n}( x )\rightarrow 0$ pointwise
- But, $f_{n}( x )\not\rightarrow 0$ uniformly
- We know $\text{max}_{x\in \left[ 0,1 \right]}\lvert f_{n}( x ) \rvert\ge \sqrt{n} \left(  1-\frac{1}{n}  \right)^{n}$ where $x=\sqrt{\frac{1}{n}}$
	- Moreover, $\sqrt{n}\left(  1-\frac{1}{n}  \right)^{n}\rightarrow \infty$
- Construct the integral: $\int_{0}^{1}f_{n}=\frac{1}{2}\frac{n}{n+1}$
- Take the limits of each for their integral and observe that: $$\lim_{n \to \infty}\int_{0}^{1}f_{n}\ne \int_{0}^{1}\lim_{n \to \infty}f_{n}( x )dx.$$

ad-theorem
 Let $( f_{n} )_{n\ge 1}$ be a sequence of functions in $R\left[ a,b \right],$ where $f_{n}$ converges to $f$ *uniformly on $\left[ a,b \right]$*. Then the following hold:
 1. $f\in R\left[ a,b \right]$
 2. $\lim_{n \to \infty}\int_{a}^{b}f_{n}=\int_{a}^{b}f$
ad-proof
Take $\theta_{n}=\text{sup}_{x\in \left[ a,b \right]}\lvert f_{n}( x )-f( x ) \rvert,$ which converges to $0$ by uniform convergence. Observe that $f_{n}-\theta _{n} \le f\le f_{n}+\theta _{n}.$ Moreover, $\overline{\int_{a}^{b}}f\le f_{n}+\theta _{n}.$ Therefore, we state that $\int_{a}^{b}f_{n}-\theta _{n} \le \underline{\int_{a}^{b}}f.$ Further, $$\begin{align} \overline{\int_{a}^{b}}f-\underline{\int_{a}^{b}}f_{n}&\le  \left(  \int_{a}^{b}f_{n}+\theta _{n}  \right)-\left(  \int_{a}^{b}f_{n}-\theta _{n}  \right) \\ &\le 2\theta _{n}( b-a )\rightarrow0 \\ \longrightarrow  \overline{\int_{a}^{b}}f&=\underline{\int_{a}^{b}}f. \end{align}$$... so, $\left\lvert  \int_{a}^{b}f_{n}-\int_{a}^{b}f  \right\rvert=\left\lvert  \int_{a}^{b}f_{n}-f  \right\rvert\le \int_{a}^{b}\lvert f_{n}-f \rvert.$ Therefore, for $\varepsilon>0,$ $\exists n_{0}$ such that if $n\ge n_{0},$ $\lvert f_{n}( x )-f( x ) \rvert<\varepsilon$ $\forall x\in \left[ a,b \right].$ Thus, $$\int_{a}^{b}\lvert f_{n}( x )-f( x ) \rvert dx \le \int_{a}^{b}\varepsilon\ dx = \varepsilon( b-a )$$.... ie. $\left\lvert  \int_{a}^{b}f_{n}-\int_{a}^{b}f  \right\rvert<\varepsilon.$
