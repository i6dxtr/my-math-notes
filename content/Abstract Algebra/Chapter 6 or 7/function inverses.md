> [!definition]
> If a [[Functions|function]] $f : A\rightarrow B$ has an inverse, it is denoted $f^{-1} : B\rightarrow A$ where $$x=f^{-1}(y) \longleftrightarrow y=f(x)$$
> ![[Pasted image 20240924142820.png]]

- for a function $f:A\rightarrow B$ to have an inverse, it must be [[bijective]]

> [!theorem]
> A function $f:A\rightarrow B$ has an inverse *if and only if* it is bijective. In that case, the inverse $f^{-1}$ is a bijective function from $B$ to $A$.
