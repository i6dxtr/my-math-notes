==recall==. if $A$ a ring, $J$ an ideal of $A$:
1. $J$ prime 
	1. then $( ab\in J\longrightarrow a\in J \vee b\in J )$
2. $J$ maximal
	1. then $J\subset A$ and there's no ideal $I$ of A s.t. $J\subset I\subset A$
==recall==. let $A$ be commutative ring w/ unity.
1. $\left\{ 0 \right\}$ is a prime ideal of $A$ $\longleftrightarrow$ $A$ is an integral domain
2. $\left\{ 0 \right\}$ is a maximal ideal of $A$ $\longleftrightarrow$ $A$ is a field
	1. ==Proof.== Suppose $\left\{ 0 \right\}$ is maximal.
		1. WTS $A$ is a field (all nonzero elements have inverse)
		2. Consider principal ideal $\left\langle a \right\rangle=\left\{ xa\ |\ x\in A \right\}$ and $\left\{ 0 \right\}\subset\left\langle a \right\rangle \subseteq A$. 
		3. Since $\left\{ 0 \right\}$ is maximal, $\left\langle a \right\rangle=A$
		4. So $1\in \left\langle a \right\rangle$, meaning $1=xa$ for some $x\in A$.
		5. Therefore, $x$ is an inverse for $a$ in $A$.
	2. Conversely, you can show if $A$ is a field, then $\left\{ 0 \right\}$ is maximal.
		1. we showed that fields have no nontrivial proper ideals.

### Chapter 19: Quotient Rings

> [!definition]
> Let $A$ be a ring and $J$ an ideal of $A$. We define their **quotient ring** as: $$A / J=\left\{ J+ x\ |\ x\in  A \right\}$$... which is a [[Rings|ring]] of [[Quotient Groups|quotient groups]] with the following operations:
> 1. Addition: $( J+ x )+( J+y )=J+( x+y )$.
> 2. Multiplication: $( J+x )( J+y )=J+xy$

> [!remark]
> Since $( A,+ )$ is an [[abelian group]] and $J$ is a [[normal subgroup]], addition of cosets is well defined and $A / J$ with addition of cosets is an abelian group.

> [!proof] Proof: $A / J$ is a ring
> 1. Suppose:
> 	1. $J+x=J+x'$
> 		1. so $x\in J+x'$
> 	2. $J+y=J+y'$.
> 		1. so $y\in J+y'$
> 2. WTS $J+xy=J+x'y'$
> 	1. $x=a+x'$ where $a\in J$
> 	2. $y=b+y'$ where $b\in J$
> 	3. $xy=( a+x' )( b+y' )=ab+ay'+x'b+x'y'\  \underline{\in J+x'y'}$ ...b/c:
> 		1.  $J$ is closed under $+$ 
> 		2. $J$ *absorbs products*
> 	4. $J+xy=J+x'y'$

> [!example]
> ##### $\mathbb{Z} / \left\langle n \right\rangle=\left\{ \left\langle n \right\rangle+0, \left\langle n \right\rangle+1,...,\left\langle n \right\rangle+( n-1 ) \right\}$
> 1. for $n\in \mathbb{Z}^{+}$: 
> 	1. $\mathbb{Z} / \left\langle n \right\rangle\cong \mathbb{Z}_{n}$
> 	2. can be seen by applying FHT to $f:\mathbb{Z}\rightarrow \mathbb{Z}_{n}, f( k )=k\text{ mod }n$

==Recall.== For a commutative ring $A$, an element $a\in A$ is *nilpotent* if $a^{n}=0$ for some $n\in \mathbb{Z}^{+}$.

> [!corollary]
> Define $K=\left\{ a\in A\ |\ a \text{ is nilpotent} \right\}$.
> Then the quotient ring $A / K$ has no nonzero nilpotent elements.

> [!proof]
> 1. Let $K+x\in A / K$.
> 2. Suppose it is nilpotent
> 	1. Then $( K+x )^{n}=0$ for some $n\in \mathbb{Z}^{+}$
> 	2. So $( K +x )^{n}=K+x^{n}=K+0$
> 	3.  WTS $K+x=K+0$
> 		1. so $x^{n}\in K+0=K$
> 		2. so $x^{n}$ is nilpotent
> 		3. so $( x^{n} )^{m}=0$ for some $m\in \mathbb{Z}^{+}$
> 		4. so $x^{nm}=0$
> 		5. thus, $x$ is nilpotent 
> 		6. therefore $x\in K$
> 		7. thus $K+x=K+0$
>
> ---
> #### Fundamental Homomorphism Theorem for rings

> [!definition]
> If $f:A\rightarrow B$ is a surjective homomorphsim and $K=\text{ker}( f )$, then $A / K\cong B$.

> [!remark]
> The kernel $K=\text{ker}( f )$ *is an ideal*, rather than a normal subgroup as it were for the definition for the fundamental homomorphsim theorem on groups.

# General Method for Well-Defined Proofs on Cosets

1. Start with sets of equivalent inputs
   - Show $a \sim a'$ (they're in same coset)
   - Show $b \sim b'$ (they're in same coset)
   
2. Express what equivalence means
   - $a - a' \in J$ or $a = a' + j_1$ where $j_1 \in J$
   - $b - b' \in J$ or $b = b' + j_2$ where $j_2 \in J$

3. Apply the operation to both versions
   - Look at $op(a,b)$ vs $op(a',b')$

4. Show their difference is in J
   - $op(a,b) - op(a',b') \in J$
   - This proves they're in same coset

5. Therefore operation is well-defined since equivalent inputs produce equivalent outputs
