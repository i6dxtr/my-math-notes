> ### Example — Non-bipartite graph with $\alpha'(G)=\beta(G)$
> An example (from lecture notes) of a non-bipartite graph $G$ for which the size of a maximum matching equals the size of a minimum vertex cover, i.e. $\alpha'(G)=\beta(G)$.
![[Pasted image 20251015132127.png|200]]

Remarks
- This example shows that equality $\lvert M\rvert=\beta(G)$ (the Kőnig–Egerváry equality) can occur in non-bipartite graphs as an instance, although Kőnig's theorem (which guarantees equality for all graphs in a class) holds only for bipartite graphs.
- Use this example when contrasting general graphs with bipartite graphs in matching/cover relations.
