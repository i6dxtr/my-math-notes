- Any image can be represented by a series of [[Matrix|matrices]], specifically:
- Images are composed of 3 matrices, respective to R, G, B in the color spectrum
	- Each entry in matrix is an integer value $[0, 255]$
	- The size of each matrix is the same as each of the image dimensions respective to the number of pixels
- Since these are matrices, we can perform a number of [[Image Operations|operations]] on them based on linear algebra
