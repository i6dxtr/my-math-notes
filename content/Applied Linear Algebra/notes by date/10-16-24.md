## Complex numbers
- $\mathbb{C}=\mathbb{R}+i\mathbb{R}$
- Any complex number $z=a+ib$
Geometrically: [[Drawing 2024-10-16 11.56.38.excalidraw]]
- Addition: $(a+bi)+(c+di)=(a+c)+(b+d)i$
	- Same as vector addition
- Modulus: $\lvert z \rvert=\lvert a+ib \rvert=\sqrt{a^{2}+b^{2}}$
- Conjugate: $\overline{z}=\overline{a+bi}=a-bi$
	- Geometrically, flips across the real axis (inversion)
	- [[Drawing 2024-10-16 12.00.15.excalidraw]]
- Multiplication: follows the rule $i^{2}=-1$
	- $(3+2i)(6-7i)=18-21i+12i-14i^{2}=32-9i$
	- Geometrically: not clear from rectangular coordinates
- $z\overline{z}=\lvert z \rvert^{2}$
- To do linear algebra over $\mathbb{C}$ we need to divide by non-zero complex numbers:
	$$
	\begin{align} \frac{a+bi}{c+di}\cdot\frac{c-di}{c-di}&=\frac{(ac+bd)+i(bc-ad)}{c^{2}+d^{2}}\\ &=\frac{ac+ab}{c^{2}+d^{2}}+i\left( \frac{bc-ad}{c^{2}+d^{2}} \right) \end{align}
	$$
- In particular, $$z^{-1}=\frac{1}{z}=\frac{1}{z}\frac{\overline{z}}{\overline{z}}=\frac{\overline{z}}{\lvert z \rvert ^{2}}$$
- if $\lvert z \rvert=1$ then $z^{-1}=\overline{z}$
- Polar Coordinates: [[Drawing 2024-10-16 12.09.56.excalidraw]]
	- $a+bi=\lvert z \rvert(\cos(\vartheta)+i \sin(\vartheta))$ where $\vartheta$ is the angle between the positive real axis
- For all real numbers $Q$ we define $$e^{i\vartheta}:= \cos(\vartheta)\sin(\vartheta)$$ ... justified by Power series
- We can rewrite the polar coordinate step as: $$z=\lvert z \rvert e^{i\vartheta}$$ ... where [[Drawing 2024-10-16 12.13.29.excalidraw]]
- Back the geometry of the fifth step:
	$$
	\begin{align} z&=\lvert z \rvert e^{i\vartheta},\\ w&=\lvert w \rvert e^{i\alpha}\\ zw&=\lvert z \rvert \ \lvert w \rvert \ e^{i\vartheta}e^{i\alpha}\\&=\lvert zw \rvert =e^{i(\vartheta+\alpha)} \end{align}
	$$


## Roots of unity
- Roots of unity: for $n=1,2,3,...$, $\zeta$ is an $n^{th}$ root of unity if: $$\zeta ^{n}=1$$
- examples:
	- $n=1$: $1$ is the only root of unity
	- $n=1$: $1$ is a $2^{\text{nd}}$ root of unity. $-1$ as well
	- $n=4$: $1$ is a $4^{\text{th}}$ root of unity. $-1$ as well
		- $i(\ i^{4}=(i^{2})^{2}=(-1)^{2}=1\ )$ , true
		- $-i\ (\ (-i)^{4}=((-i)^{2})^{2}=(-1)^{2}\ )$ , true

#### Remarks
1. If $\alpha$ is an $n^{\text{th}}$ root of unity and $k=1,2,3,...$ then $\zeta$ is an $nk^{\text{th}}$ root of unity. Then $\zeta ^{nk}-(\zeta ^{n})^{k}=1^{k}=1.$
2. If $\zeta$ is a $n^{\text{th}}$ root of unity then $\lvert \zeta \rvert=1$
	1. $(\ (\lvert \zeta ^{n} \rvert=1\longrightarrow \lvert \zeta \rvert^{n}=1 \rightarrow\lvert \zeta \rvert=1$
	2. $(\zeta ^{-1})^{n}=\left( \frac{1}{\zeta ^{n}} \right)=\frac{1}{1}=1$, so $\zeta ^{-1}$ is an $n^{\text{th}}$ root
	3. But, since $\lvert \zeta \rvert=1$, we have $\zeta ^{-1}=\overline{\zeta}$
3. If $\zeta_{1}, \zeta _{2}$ are $n^{\text{th}}$ roots of unity, then so is $\zeta_{1}\zeta_{2}$
	1. $(\zeta_{1}\zeta_{2})^{n}=\zeta_{1} ^{2}\zeta_{2} ^{n}=1\cdot1=1$
note that this forms a group

Using the complex exponential, we can list all $n^{\text{th}}$ roots of unity: $$\zeta_{n}=e^{2\pi i/n}\ \ (e^{2\pi i}=\cos(2\pi)+i\sin(2n)=1)$$
$$1, \zeta_{n}, \zeta_{n}^{2}, ..., \zeta_{n}^{n-1}$$
Equivalently, we can list them as: $$\left\{ e^{2\pi i/n}\ :\ k=0,1,...,n-1 \right\}$$
