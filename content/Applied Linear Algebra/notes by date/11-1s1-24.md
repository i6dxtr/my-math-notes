### Spectral Theorem
##### Kind of a definition
let $A=A^{T}$. Then there is an orthogonal matrix $Q$ and diagonal $D$ such that: $$A=ADA$$
- ... where the columns of $Q$ are eigenvectors of diagonal entries of $D$
- Eigenvalues $D\left[ i,i \right]$ for $0\le i\le n$ (?)
#### Constructing a symmetric $A$ with eigenvalues
- We want to set eigenvalues $\lambda=2, \lambda=-1$ and eigenvectors $E_{1}=\begin{pmatrix} \frac{2}{\sqrt{13}}\\\frac{3}{\sqrt{13}} \end{pmatrix}$, $E_{2}=\begin{pmatrix} -\frac{3}{\sqrt{13}}\\ \frac{2}{\sqrt{13}} \end{pmatrix}$
- We diagonalize $D=\begin{pmatrix} 2&0\\0&-1 \end{pmatrix}$. 
	- Currently have correct eigenvalues, but wrong eigenvectors
- See: $$A=\begin{pmatrix} \frac{2}{\sqrt{13}}&-\frac{3}{\sqrt{13}}\\\frac{3}{\sqrt{13}}&\frac{2}{\sqrt{13}} \end{pmatrix}\begin{pmatrix} -2&0\\0&-1 \end{pmatrix}\begin{pmatrix} \frac{2}{\sqrt{13}}&\frac{3}{\sqrt{13}}\\-\frac{3}{\sqrt{13}}&\frac{2}{\sqrt{13}} \end{pmatrix}=\frac{1}{13}\begin{pmatrix} -1&18\\18&14 \end{pmatrix}$$
	- First matrix is $Q$
- Numpy can generate random symmetric matrices with given eigenvalues $( \lambda_{0}, \lambda_{1},...\lambda_{n-1} )$
	- $A$ = np.random.rand(n,n) ... return $A+A.T$
	- $A = QR$
		- $Q$ is an orthonormal basis for $\mathbb{R}^{n}$
		return $Q$ @ diag($\lambda_{1},...,\lambda_{n-1}$)
- Recall positive semi-definite matrices (PSD)
1. $A=A^{T}$
	1. $Q^{T}AQ\mathbf{x}\cdot\mathbf{x}=AQ\mathbf{x}\cdot Q\mathbf{x}$
2. $A\mathbf{x}\cdot \mathbf{x}\ge 0$  $\forall\mathbf{x}\in \mathbb{R}^{n}$
- We saw earlier that $PSD\longrightarrow$ all eigenvalues are $\ge0$
- Obtain a characterization of PSD matrices in terms of diagonal values: $$\begin{pmatrix} 5&0&0\\0&3&0\\0&0&-1 \end{pmatrix}\begin{pmatrix} x_{1}\\x_{2}\\x_{3} \end{pmatrix}\begin{pmatrix} x_{1}\\x_{2}\\x_{3} \end{pmatrix}=5x_{1}^{2}+3x_{2}^{2}-x_{3}^{2}$$
- so the diagonal D$=-1<0$, so not PSD: $$D\begin{pmatrix} 0\\0\\1 \end{pmatrix}\begin{pmatrix} 0\\0\\1 \end{pmatrix}=-1<0$$
- take diagonal $A$ and multiply by squared vector: $$A=\begin{pmatrix} 5&0&0\\0&3&0\\0&0&1 \end{pmatrix}\begin{pmatrix} x_{1}\\x_{2}\\x_{3} \end{pmatrix}\begin{pmatrix} x_{1}\\x_{2}\\x_{3} \end{pmatrix}=5x_{1}^{2}+3x_{2}^{2}+x_{3}^{2}\ge 0$$
	- clearly greater than 0, so it's PSD
- ==Guess==: A diagonal matrix $D$ is PSD *iff* the diagonal entries are nonnegative, via the spectral theorem.
- Conversely, suppose that all eigenvalues of $A$ are $\ge0$, so $D$ is diagonal.
	- So $A=A^{T}$
	- Get $Q$ so $QAQ^{T}=D$ where $D$ is diagonal.
	- Diagonal entries of $D$ are $\ge0$ so $D$ *is* PSD.
	- Then, $A=Q^{T}QAQ^{T}Q=Q^{T}DQ$ is also PSD.
- We obtain the fact $A=A^{T}$ is PSD *iff* all eigenvalues are nonnegative
