#### Finishing QR algo
==Recall==: $A$ is $n \times k$ with linearly independent columns
- Output: $A=QR$
	- $Q$ is $n \times k$ with ON columns that form ONB for $\text{col}(A)$
	- $R$ is $k \times k$ upper triangle
	- $\text{span}\ {\left\{ A[:,0],...,A[i,j] \right\}}=\text{span}\left\{ Q[:,0],...,Q[:,i] \right\}$
	- 1 + 3 = 2 (steps)
	==Recall==: $P$ projects onto $H$. THen the projection onto $H^{\perp}$ is $\mathbb{1}_{n}-P$
==Notation==: $\left\{ q_{1},...,q_{i} \right\}$ are orthonormal vectors (side note: notation of $q$ probably wrong)
$$P_{\left\{ q_{1},...,q_{i} \right\}}=\text{Projection onto span}\left\{ q_{1},...,q_{n} \right\}$$

example code
- $n,k$=A.shape
- $Q_{0}=\frac{A[:.0]}{\lvert \lvert\  A[:,0]\  \rvert \rvert}$
- for i=1,...,k-1:
$$Q_{i}=\frac{P_{\left\{ Q_{0},...,Q_{i-1} \right\}}^{\perp}(A[:,i])}{\lvert \lvert P_{\left\{ Q_{0},...,Q_{i-1} \right\}}^{\perp} (A[:,i])\rvert  \rvert }$$
- return $[Q_{0}Q_{1}\cdots Q_{k-1}]$

#### Using QR algorithm as a guide
Suppose $A=QR$, then we see that:
- $AR^{-1}=Q$
- $A^{T}A=R^{T}Q^{T}QR=R^{T}R$
	- has orthonormal columns
- $(A^{T}A)^{-1}=(R^{T}R)^{-1}=R^{-1}T^{-T}$
so $QQ^{T}=(AR^{-1})(R^{-T}A^{T})=A(A^{T}A)^{-1}A^{T}$
- it seems like calculating inverses are "expensive", but we can eliminate them using least squares
**Least Squares**
- A is $n \times k$ with linearly independent columns, and $b$ is an $n \times 1$ vector. Find $\overline{x}\in\mathbb{R}^{k}$ that minimizes $\lvert \lvert A\overline{x}-b \rvert \rvert$
		- "Easy": SOlve $A\mathbf{x}=Pb$ where $P$ projects onto $\text{col}(A)$
		- Use $Q$ from $QR$ to find $P$ s.t.:
		$A\mathbf{x}=QQ^{T}\cdot b$
... so $A(A^{T}A)^{-1}A^{T}$ projects onto $\text{col}(A)$. We then solve:
- $A\mathbf{x}=A(A^{T}A)^{-1}A^{T}b$
- $\mathbf{v}=(A^{T}A)^{-1}A^{T}b$
- $A^{T}A\mathbf{x}=A^{T}b$
- $A^{T}A\ |\ A^{T}b$
